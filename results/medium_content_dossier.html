Site Structure

Medium's structure is content-type based rather than category-based like a storefront — the same navigation surfaces stories from thousands of independent publications and authors.

Topic Hubs

/tag/{topic}
  • Discovery surface — this workflow's main entry point
  • e.g. self-improvement, psychology, productivity
  • No pagination API — reached via scroll/JS render

Publications

medium.com/{pub-name}
  • Editorially curated collections (e.g. Illumination, Publishous)
  • Own masthead, own editorial voice/quality bar
  • Mixed reliability — verify regardless of publication

Author Pages

/@handle or {name}.medium.com
  • Independent writers, some with custom subdomains
  • No editorial gate — quality varies writer to writer

Story Pages

/{pub-or-@author}/{slug}-{hash}
  • Single article; the actual scrape target
  • Member-only stories show a paywall after ~1 paragraph

Membership Gate

Cuts across all content types
  • Member-only flag is per-story, not per-publication
  • 23 of 30 sourced stories in this run were gated

Utility

Site-wide
  • Help, Status, About, Careers, Press, Store
  • policy.medium.com — Terms, Privacy, Rules (separate subdomain)
